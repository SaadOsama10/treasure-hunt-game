🗺️ Treasure Hunt Adventure

A two-level dice-roll board game in Java Swing, built on custom linked lists and a binary search tree. It runs here, in your browser, with CheerpJ (Java in WebAssembly): no install, no server.

⏳ The first load downloads the Java runtime and can take a few seconds (up to a minute on a slow connection). Use a desktop browser; the game is mouse-only.

How to play

  1. Click Start Game, type a username and press Enter.
  2. Level 1: click Roll Dice. Your pirate walks that many tiles: chest +10, trap −5, empty tile nothing.
  3. Reach the last tile, then choose to continue to Level 2, which adds tiles that push you forward or backward.
  4. Open the Score Board, enter a username and see that player's scores, best and worst.

About

  • Data Structures course project by Saed O S Radi and Abdulrahman Zeineddin (FSMVU).
  • Boards are generic linked lists; the scoreboard is a binary search tree.
  • Scores are kept in your browser's storage (CheerpJ /files/); clearing site data erases them.
